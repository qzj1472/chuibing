# Chuibing

The handle that makes the hammer comfortable.

</div>

**Chuibing** is a patch tool for Smartisan OS. Root required.

A hammer is only as nice as its handle. This app is that handle: TNT windows, voice commands, and system WebView, turned into taps instead of hunting through system files.

What it does:

- Edit TNT window size, display mode, and resize rules in a GUI
- Group apps and apply one window spec to a whole collection
- Switch TNT mirror / desktop / share, and open the virtual touchpad
- Expand voice commands and aliases for the virtual remote
- Switch the system WebView implementation

It backs up the original files on first launch. System XML is written only when you save. Voice and WebView features need an LSPosed module.

## Notes

- It edits system files. Uninstalling the app does not restore them.
- Use only on your own rooted device.
